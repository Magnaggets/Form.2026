
# FORM — персональный фитнес-трекер

FORM — веб-приложение для ведения тренировок, сохранения результатов, отслеживания прогресса и формирования полезных тренировочных привычек.

Сайт помогает организовать занятия в одном месте: от записи упражнений и рабочих весов до просмотра истории тренировок, выполнения недельных целей и получения наград.

## Основные возможности

### Создание и сохранение тренировок

Пользователь может создавать тренировки и записывать результаты выполненных упражнений.

Для каждой тренировки можно указать название, заметки и список упражнений с рабочим весом, количеством повторений и подходов.

После заполнения формы тренировка сохраняется, а информация становится доступна для дальнейшего просмотра и анализа.

### Каталог упражнений

В FORM предусмотрен каталог упражнений для подбора упражнений в тренировочный план.

В каталоге доступны поиск по названию, фильтрация по группам мышц, анимированные изображения техники выполнения при их наличии, сведения о задействованных мышцах и оборудовании, инструкции для некоторых упражнений и добавление выбранного упражнения непосредственно в форму тренировки.

Названия упражнений, группы мышц и оборудование отображаются на русском языке там, где предусмотрен перевод. Полнота перевода зависит от словаря каталога.

### История тренировок

Сохранённые тренировки можно просматривать в истории занятий. Это позволяет возвращаться к предыдущим результатам, сравнивать рабочие веса и повторения, а также оценивать изменения тренировочной нагрузки со временем.

### Статистика и прогресс

Сайт отображает статистику тренировочной активности на основе сохранённых данных. Она помогает отслеживать количество проведённых тренировок, активность за текущую неделю, выполнение целей и изменения результатов.

### Недельная цель

В приложении предусмотрена цель по количеству тренировок за неделю. Стандартное значение — 3 тренировки в неделю.

Индикатор прогресса показывает, сколько занятий уже выполнено и сколько осталось до достижения цели. После выполнения цели сайт отображает соответствующее сообщение.

### Достижения и награды

В FORM предусмотрена система достижений, связанная с тренировочной активностью. Она предназначена для дополнительной мотивации, фиксации результатов и поощрения регулярных занятий.

Конкретные условия получения достижений зависят от реализованных правил системы наград.

## Как пользоваться FORM

### Шаг 1. Откройте страницу тренировок

Перейдите к форме создания тренировки.

### Шаг 2. Создайте тренировку

Укажите название тренировки. При необходимости добавьте заметки с описанием занятия.

### Шаг 3. Добавьте упражнения

Введите упражнения вручную или воспользуйтесь каталогом. При добавлении упражнения из каталога его название автоматически переносится в форму.

### Шаг 4. Заполните результаты

Для каждого упражнения укажите вес в килограммах, количество повторений и количество подходов.

### Шаг 5. Сохраните тренировку

Нажмите кнопку сохранения. Если данные заполнены корректно и сервер доступен, тренировка будет сохранена.

### Шаг 6. Следите за прогрессом

Просматривайте историю занятий, статистику, выполнение недельной цели и доступные достижения.

### Шаг 7. Используйте каталог

Введите название упражнения в поиск или выберите группу мышц. Изучите доступную информацию и добавьте подходящее упражнение в тренировку.

## Особенности проекта

FORM объединяет ведение тренировок, каталог упражнений, историю занятий и контроль целей в одном приложении.

Каталог позволяет быстрее заполнять тренировочную форму, а статистика и недельная цель помогают следить за регулярностью занятий. Проект также можно расширять новыми функциями планирования, аналитики и персональных настроек.

## Технологии

В проекте используются HTML, CSS и JavaScript для создания интерфейса, интерактивности и взаимодействия с сервером.

Серверная часть построена на Python и Flask, если эти технологии используются в текущей конфигурации проекта. Для обмена данными применяется REST API, а для хранения данных используется настроенная база данных или другой формат хранения.

Для получения упражнений и анимированных изображений используется внешний источник ExerciseGymGifsDB.

## Цель проекта

Цель FORM — упростить ведение тренировок, сделать результаты занятий доступными для анализа и объединить запись упражнений, статистику и систему целей в одном веб-приложении.

Проект может служить основой для дальнейшего развития персонального фитнес-сервиса с расширенной аналитикой, индивидуальными планами тренировок, системой пользователей и дополнительными инструментами контроля прогресса.
