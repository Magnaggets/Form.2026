
# FORM — персональный фитнес-трекер

FORM — веб-приложение для ведения тренировок, сохранения результатов и отслеживания физического прогресса. Сайт объединяет журнал тренировок, каталог упражнений, статистику, недельные цели и систему достижений.

## Возможности

### Тренировки

Пользователь может создавать тренировки, задавать им названия и добавлять заметки. Для каждого упражнения указываются рабочий вес, количество повторений и подходов.

Сохранённые тренировки используются для ведения истории занятий и отображения статистики.

### Каталог упражнений

Каталог помогает находить упражнения и добавлять их в тренировочную форму.

Доступны поиск по названию, фильтрация по группам мышц, анимированные изображения упражнений при наличии, информация об оборудовании и мышцах, а также инструкции по технике выполнения для некоторых упражнений.

Для получения каталога используется внешний проект [ExerciseGymGifsDB](https://github.com/JahelCuadrado/ExerciseGymGifsDB). Для работы изображений и каталога может потребоваться подключение к интернету.

### История и статистика

История позволяет просматривать сохранённые занятия и возвращаться к предыдущим результатам.

Статистика помогает отслеживать тренировочную активность и изменения показателей на основе сохранённых данных.

### Недельная цель

В приложении предусмотрена недельная цель — стандартно 3 тренировки. Индикатор прогресса показывает количество выполненных занятий и оставшихся до достижения цели.

### Достижения

Система достижений предназначена для отслеживания результатов и дополнительной мотивации к регулярным занятиям.

## Как пользоваться сайтом

### 1. Создание тренировки

Откройте страницу тренировок и найдите форму создания занятия. Укажите название тренировки и при необходимости добавьте заметки.

### 2. Добавление упражнений

Введите название упражнения вручную либо воспользуйтесь каталогом. При выборе упражнения из каталога его название автоматически переносится в форму тренировки.

### 3. Заполнение результатов

Для каждого упражнения заполните вес в килограммах, количество повторений и подходов. Проверьте введённые данные.

### 4. Сохранение

Нажмите кнопку сохранения тренировки. При корректно заполненной форме и доступном сервере данные будут отправлены через API и сохранены.

### 5. Отслеживание прогресса

После сохранения можно просматривать историю тренировок, статистику, недельную цель и доступные достижения.

### 6. Поиск упражнений

Введите название упражнения в поисковую строку или выберите группу мышц. Изучите доступную информацию и добавьте подходящее упражнение в тренировку.

## Как запустить проект локально

Для запуска понадобится установленный Python и Git. Команды ниже предназначены для Windows и терминала PowerShell в Visual Studio Code.

### 1. Скачайте репозиторий

Клонируйте проект с GitHub:

```powershell
git clone https://github.com/ВАШ_АККАУНТ/FORM.git
cd FORM
```

Замените `ВАШ_АККАУНТ` на имя своего аккаунта GitHub.

Если проект уже открыт в VS Code, повторно клонировать его не нужно.

### 2. Создайте виртуальное окружение

```powershell
python -m venv .venv
```

Активируйте его:

```powershell
.\.venv\Scripts\Activate.ps1
```

Если PowerShell блокирует активацию, можно запустить Python из виртуального окружения напрямую, не меняя системные настройки.

### 3. Установите зависимости

Если в проекте есть файл `requirements.txt`, выполните:

```powershell
python -m pip install -r requirements.txt
```

Если такого файла нет, сначала необходимо определить зависимости проекта и создать его. Не устанавливайте пакеты наугад.

### 4. Настройте переменные окружения

Если проект использует файл `.env` для настроек или секретов, создайте его на основе предусмотренного в проекте примера. Не публикуйте пароли, токены и секретные ключи в GitHub.

Если дополнительные переменные окружения не используются, этот шаг можно пропустить.

### 5. Запустите сервер

Если главный файл приложения называется `app.py` и Flask настроен для запуска через него:

```powershell
python app.py
```

Если в проекте используется другое имя главного файла или отдельная команда запуска, используйте соответствующую команду из кода проекта.

После запуска Flask выведет локальный адрес, обычно `http://127.0.0.1:5000`. Откройте указанный адрес в браузере.

Оставьте терминал с работающим сервером открытым. Чтобы остановить сервер, нажмите `Ctrl + C`.

### 6. Проверьте работу приложения

Убедитесь, что открываются страницы, работают формы, загружается каталог упражнений и сохраняются тренировки.

Для функций, связанных с сервером, одного открытия HTML-файла недостаточно: Flask и API должны работать.

## Технологии

HTML и CSS используются для структуры и оформления страниц. JavaScript отвечает за интерактивность, формы, поиск упражнений и взаимодействие с сервером. Серверная часть проекта использует Python и Flask, если это соответствует текущей конфигурации приложения.

REST API обеспечивает обмен данными между интерфейсом и сервером. Для хранения данных используется настроенное в проекте хранилище.
